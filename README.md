## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### 1. Clone & Enter Directory
```bash
cd portfolio-v1
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 4. Build for Production
```bash
npm run build
```
Production assets are generated in the `dist/` directory.

### 5. Run Linter
```bash
npm run lint
```

## ⚙️ Environment Variables (Optional)

To configure dynamic contact form submissions via EmailJS, create a `.env` file in the root directory:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

*Note: If these variables are not configured, the contact form automatically falls back to opening the visitor's mail client directly to `ajaytandale8983@gmail.com`.*
